The Gas Station Management System is a Java-based application developed using Object-Oriented Programming (OOP) principles. The project simulates the main operations of a gas station, including fuel management, pump transactions, customer management, employee management, payments, loyalty programs, and fuel delivery orders.
The system demonstrates how different classes and objects can work together to represent a real-world gas station environment.

Features
* Manage gas pumps and fuel types
* Calculate fuel costs and record transactions
* Manage customer information and loyalty points
* Manage employees and their tasks
* Support different payment methods, including cash and credit card
* Award and redeem customer loyalty points
* Create and manage fuel delivery orders
* Generate sales reports
* Monitor fuel levels and transaction history

## Main Components
The system is organized into several classes:
* GasStation – Manages pumps, employees, fuel inventory, and transactions.
* GasPump – Handles fueling sessions and fuel dispensing.
* FuelType – Stores fuel types and their prices.
* Transaction – Records fuel purchases and payment information.
* Employee – Represents gas station employees and their tasks.
* Customer – Stores customer information and loyalty points.
* PaymentMethod – Defines the general payment structure.
* CashPayment – Handles cash payments and change.
* reditCardPayment – Handles credit card payments.
* LoyaltyProgram – Manages customer points and rewards.
* FuelOrder – Manages fuel delivery orders and their status.

## Object-Oriented Programming Concepts
This project demonstrates several fundamental OOP concepts:
* Encapsulation – Organizing data and related methods within classes.
* Inheritance – Using specialized payment classes that inherit from `PaymentMethod`.
* Abstraction – Defining common payment behavior through an abstract payment method.
* Polymorphism – Allowing different payment types to implement their own payment-processing behavior.


## Project Purpose
The main purpose of this project is to apply Object-Oriented Programming concepts to a practical real-world system. It provides experience in designing classes, establishing relationships between objects, implementing inheritance and abstraction, and organizing a Java application in a structured and maintainable way.
The system demonstrates how different classes and objects can work together to represent a real-world gas station environment.
